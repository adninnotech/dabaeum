== Credential

=== 발급 요청

확정(`COMPLETED`) 이수에 대한 명시적 발급 요청입니다. 호출자는
`PLATFORM_ADMIN` 또는 해당 과정 기관의 `INSTITUTION_ADMIN`이어야 하며,
`Idempotency-Key` 헤더는 8~128자로 필수입니다. 응답 `202 Accepted`의 Credential은
`PENDING` 상태이며, Fabric 호출은 이 요청 트랜잭션에서 수행하지 않습니다.

=== 상세 조회

Credential 상세는 본인, 해당 과정 기관 관리자 또는 `PLATFORM_ADMIN`만 조회할 수 있습니다.
`vcPayload`, proof 원문, private key, Fabric 인증정보는 응답에 포함하지 않습니다.
`PENDING`·`ISSUING`·`ISSUED`·`FAILED` 상태를 이 API로 polling합니다.

=== 폐기·재발급 요청

폐기와 재발급은 Fabric 제출과 DB 상태 확정을 분리한 비동기 요청입니다. 기관 관리자 또는
플랫폼 관리자만 호출할 수 있고 `Idempotency-Key`와 사유가 필수입니다. `202 Accepted` 직후
폐기 대상은 `ISSUED`, 재발급 신규 Credential은 `PENDING`이며 상세 조회로 확정 상태를
polling합니다. 원장 응답이 유실되면 읽기 전용 reconciliation이 해시와 상태를 대조합니다.

=== 공개 검증

인증 없이 `credentialNo` 또는 `credentialHash` 중 정확히 하나만 제출합니다. raw VC/proof는
받지 않으며, proof·저장 envelope hash·Credential 상태·유효기간·Fabric 읽기를 모두 통과해야
`VALID`입니다. 원장 장애는 `ERROR`로 기록하며 성공으로 추정하지 않습니다.
